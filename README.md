# RGG Road

Воксельный бесконечный хоппер на **Three.js + TypeScript + Vite**, вдохновлённый
механиками классической **Crossy Road**, но с собственными моделями, материалами,
звуками и кодом. Это самостоятельный проект, а не ремейк с ассетами оригинала.

Бесконечные дороги, реки, поезда, четырнадцать биомов, монеты, скины и сохранение
прогресса. Работает в браузере на десктопе и телефонах.

**Играть онлайн:** https://wanterlude.github.io/rggroad/

## Управление

- **WASD** или **стрелки** — шаг вперёд/назад/влево/вправо.
- **Свайп** или **тап** на телефоне.
- **Esc** / **P** — пауза, **M** — звук.
- Игра запускается только кнопкой **«ИГРАТЬ»**.

## Биомы

Классические: `autumn`, `forest`, `desert`, `ocean`, `frost`, `lava`, `void`.
Добавленные: `candy`, `savanna`, `jungle`, `city`, `space`, `prehistoric`,
`halloween`.

У каждого биома своя палитра, реквизит, плотность трафика и активные механики:
орёл/стервятник уносит за бездействие, крокодилы опасны головой, лилии служат
островками, поезда гудят и мигают переездами, а в доистории поезд заменён
стампедой пахицефалозавров.

## Возможности

- Бесконечная генерация рядов: лужайки, дороги, реки с брёвнами, железнодорожные
  переезды; сложность и плотность трафика растут с дистанцией.
- Диагональная ортографическая изометрия в геймплее и в живом меню.
- Процедурные текстуры, модели, музыка и SFX — без внешних ассетов (кроме
  арт-портретов персонажей).
- Сохранение рекорда, монет, выбранного героя и настройки звука в `localStorage`.
- Адаптивная камера и интерфейс для десктопа, портретного телефона и короткого
  ландшафтного экрана.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`.

### Тестовые параметры

- `?coins=max` — выдать монеты для проверки магазина; то же из консоли:
  `CR3D.setCoins("max")`.
- `?eyes=1`…`?eyes=20` — варианты глаз itsMORIKO.
- `?debug=1` — отладочная строка состояния.

## Сборка

```bash
npm run build
```

Результат — **один файл** `dist/index.html`: JavaScript и CSS встроены через
`vite-plugin-singlefile`. Его можно открыть напрямую через `file://` или положить
на любой статический хостинг.

```bash
npm run preview   # локальный просмотр production-сборки
npm run typecheck # проверка типов
```

## Структура проекта

```
index.html          — разметка интерфейса и меню
styles.css          — стили, адаптивность, модальные окна
src/
  main.ts           — точка входа, публичное API CR3D
  Game.ts           — состояния игры, камера, ввод, смерть/рестарт
  World.ts          — генерация рядов, машины, брёвна, поезда, монеты
  SceneView.ts      — рендер, окружение, частицы
  Models.ts         — воксельные модели всех персонажей
  Portraits.ts      — арт-карточки и портреты
  RowModels.ts      — модели машин, поездов и реквизита
  biomes.ts         — четырнадцать биомов и их механики
  AudioEngine.ts    — процедурная музыка и SFX
  save.ts           — сохранение прогресса
  assets/           — портреты, арт, монеты, GLB-модель
docs/index.html     — single-file сборка для GitHub Pages
```

## Технологии

- **Three.js** 0.186, ортографическая камера, instanced-меши.
- **TypeScript** 5.9, строгая типизация.
- **Vite** 8 + `vite-plugin-singlefile`.
- **WebAudio** для процедурного звука.
- **localStorage** для прогресса.

## Дисклеймер

RGG Road — самостоятельный независимый проект. Crossy Road — торговая марка
