# RGG Road

Воксельный бесконечный хоппер на **Three.js + TypeScript + Vite**, вдохновлённый
механиками классической **Crossy Road**, но с собственными моделями, материалами,
звуками и кодом. Это самостоятельный проект, а не ремейк с ассетами оригинала.

Бесконечные дороги, реки, поезда, четырнадцать биомов, монеты, скины и сохранение
прогресса. Работает в браузере на десктопе и телефонах.

## Быстрый запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`.

### Тестовые монеты

Для быстрой проверки магазина откройте игру с параметром `?coins=max`:
`http://127.0.0.1:5173/?coins=max`. То же самое можно сделать из консоли:
`CR3D.setCoins("max")`. Значение сохраняется в текущем профиле.

### Тестовые глаза Моряки

Варианты глаз переключаются параметром `?eyes=1`…`?eyes=20`. Общий лист
вариантов — [preview-eyes-1154295bfb.jpg](preview-eyes-1154295bfb.jpg).

### Сборка

```bash
npm run build
```

Результат — **один файл** `dist/index.html`: JavaScript и CSS встроены через
`vite-plugin-singlefile`. Его можно открыть напрямую через `file://`.

```bash
npm run preview   # локальный просмотр production-сборки
npm run typecheck # проверка TypeScript
```

## Что внутри

- **Живое меню** — фоном идёт настоящая игра: автопилот-бот проходит бесконечный
  забег. Он планирует маршрут на несколько секунд вперёд, учитывает скорость машин,
  брёвен и поездов, ждёт безопасные окна, обходит препятствия и не останавливается
  на дорогах и рельсах. Если бот всё-таки погибает, демо автоматически
  перезапускается в следующем биоме. В самом демо биом меняется каждые 15 рядов.
  Камера следует за ботом, а поверх лежат полка персонажей, рекорд, монеты и
  кнопка «Играть». Карточки персонажей показывают только голову, а выбор героя
  сразу меняет модель в живом демо.
- **Семь новых биомов** — всего 14: саванна, джунгли, город, космос, сладости,
  доистория и Хэллоуин добавлены к классическим. У каждого свои палитра, реквизит,
  плотность трафика и активные механики.
- **Опасности из оригинала** — орёл/стервятник уносит игрока за 15 секунд
  бездействия или три шага назад; на 10-й секунде появляется предупреждение с
  обратным отсчётом. Крокодилы опасны только головой, а по телу можно ехать;
  лилии служат неподвижными островками; полицейские машины включают маячки;
  в доистории поезд заменён стампедой пахицефалозавров.
- **Без постоянной цветокоррекции** — свет, туман и фон остаются нейтральными;
  биомы различаются материалами и окружением, а не постоянным фильтром поверх
  всей сцены. На стыке биомов есть короткая нейтральная туманная перемычка.
- **Увеличенная дальность полос** — ряды дорог держатся далеко за краями кадра,
  поэтому разметка не возникает и не исчезает на глазах. Каменная стена и туннели
  убраны — они не подходили стилю.
- **Скрытые границы карты** — ряды расширены до 150 единиц, а игрок мягко
  ограничен по горизонтали. Камера не видит обрыв карты, зелёную пустоту с
  машинами и брёвнами за краем полос.
- **Чистый высококачественный рендер** — полноценное разрешение экрана,
  сглаживание, devicePixelRatio до 2× и линейная фильтрация процедурных текстур.
- **Диагональная ортографическая изометрия** в геймплее и в живом меню, как в
  оригинале: полосы дорог идут под углом, нет перспективного схождения и линии
  горизонта.
- **HUD в духе оригинала** — крупный белый счёт с чёрным контуром, монета со
  свином и отдельная кнопка паузы.
- **Переработанный транспорт** — у машин, фургонов, грузовиков и автобусов
  выровнены колёса, кузова, стёкла, бамперы и крыши. Добавлены гоночная машина
  со спойлером и двухэтажный автобус; полицейские получили световую балку.
  Внутри одной полосы все машины едут с одинаковой скоростью, поэтому не
  догоняют и не наезжают друг на друга.
- **Плавные переходы биомов** — на границе на короткое время включается мягкая
  нейтральная туманная завеса, скрывающая резкую смену палитры.
- **Звук под биом** — к процедурной музыке добавлен тихий эмбиент-аккорд, который
  меняет тональность и фильтр для каждого из 14 биомов.
- **Шоколадные и ледяные платформы** — в сладостях по рекам плывут шоколадные
  плиты, во льдах и космосе — ледяные льдины.
- **Сигналы переезда** — красные мигающие огни, крестовины и гудок предупреждают
  о поезде заранее.
- **Бесконечная генерация** — безопасные лужайки, дороги, реки с брёвнами и
  лилиями, железнодорожные переезды. Сложность и плотность трафика растут с
  дистанцией.
- **Монета со свином** — лицевая сторона с портретом свина, обратная — «1 КРЫ СУБЛЬ».
  В мире монета вращается и показывает обе стороны, в HUD используется лицевая.
  Иллюстрации монеты предоставлены автором проекта.
- **Moryaka** — воксельная героиня: лисьи ушки, очки на лбу, белая прядь,
  коричневые twin-массы волос, бело-фиолетовый костюм с жёлтыми акцентами,
  большие лапы и полосатый хвост. Собственная 3D-модель, портрет для карточки.
  Все персонажи сейчас бесплатны.
- **SeverinaSoda** — чиби-героиня в фиолетовом костюме удильщика: огромный капюшон,
  светящаяся приманка, глаза на капюшоне, плавники, золотой бубенчик, лавандовые
  волосы и сонные бирюзовые глаза.
- **HiganBanban** — зеленоволосая героиня с красными прядями, длинным ахоге,
  огненными глазами, чёрно-зелёным костюмом с черепами и большой красной
  лилией-хиганбаной в волосах.
- **Ditoshey** — розово-лавандовая кицунэ с четырьмя пушистыми ушками,
  длинными косами, круглыми очками, зелёными глазами и сиреневым
  костюмом-скелетом с красным сердцем.
- **Персонажи бесплатно** — все четырнадцать героев открыты и доступны сразу,
  без покупки. Монеты остаются на HUD и могут пригодиться для будущих наград.
- **Сохранение** — рекорд, монеты, выбранный скин, разблокировки и настройка звука
  хранятся в `localStorage`.
- **Процедурный звук** — музыка и SFX синтезируются через WebAudio, без внешних
  аудиофайлов.
- **Адаптивность** — отдельные масштабы ортографической камеры для десктопа,
  портретного телефона и короткого ландшафтного экрана. В коротком ландшафте меню
  собирается в компактную нижнюю панель.
- **Blob-тени и instancing** — вместо тяжёлых shadow maps используются мягкие
  тени-пятна; машины, кубы рядов и реквизит рисуются через `InstancedMesh`.

## Механики

- Игрок — маленькая воксельная фигурка на сетке. Каждый свайп, тап или нажатие
  стрелки перемещает её на одну клетку вперёд, назад, влево или вправо.
- Мир состоит из горизонтальных рядов: безопасная трава, дороги с машинами,
  реки с движущимися брёвнами, крокодилами и лилиями, железнодорожные пути.
- Машина, поезд, крокодил или падение в воду заканчивают забег. На травяных рядах
  тоже нельзя стоять вечно: через 15 секунд бездействия или после трёх шагов назад
  прилетает орёл (в разных биомах — стервятник, летучая мышь, НЛО, птеродактиль
  или сладкий самолётик). На 10-й секунде появляется предупреждение и обратный
  отсчёт.
- Крокодил — не просто бревно: его спина и хвост безопасны, а голова съедает.
  Лилия — статичная безопасная платформа посреди реки. В сладостях встречаются
  шоколадные плиты, во льдах и космосе — льдины.
- Полицейские машины в городе включают красно-синие маячки. В одной полосе
  скорость транспорта синхронизирована, чтобы машины не перекрывали друг друга.
  В доистории вместо поезда мчится стадо пахицефалозавров.
- За каждый новый ряд начисляется очко. Рекорд сохраняется между запусками.
- Монеты собираются на поле и на дорогах. Все персонажи сейчас доступны бесплатно;
  монеты остаются как счётчик и задел для будущих наград.
- Каждые 30 рядов меняется биом: материалы, реквизит, плотность и тип препятствий
  обновляются, а на границе срабатывает мягкая туманная перемычка без глобального
  цветофильтра.
- Камера следует за игроком с демпфированием, поэтому персонаж остаётся в нижней
  части экрана, а мир прокручивается вперёд.

## Биомы

Всего 14 биомов, по 30 рядов на биом. Порядок выстроен от простых и светлых
ландшафтов к плотным, быстрым и тёмным:

1. Зелёные луга — спокойный старт: дороги, брёвна и поезда.
2. Зелёный лес — тот же ритм, но плотнее реквизит.
3. Тропический океан — больше воды и длинные реки.
4. Саванна — открытые луга, стервятник и крокодилы.
5. Пустыня — крокодилы, песчаные камни, больше дорог.
6. Ледяные пустоши — ледяные платформы и скользкая палитра.
7. Сладости — шоколадные реки, сладкий самолёт вместо орла.
8. Джунгли — много воды, лилии и крокодилы.
9. Город — плотные дороги и быстрые полицейские машины.
10. Доистория — крокодилы, птеродактиль и стампида вместо поезда.
11. Хэллоуин — летучая мышь, тыквы, тёмная вода.
12. Пекло — быстрый трафик и раскалённая палитра.
13. Космос — НЛО, льдины и неоновые линии.
14. Пустота — самый тёмный и быстрый финал: НЛО и ледяные платформы.

В демо-меню биом меняется каждые 15 рядов, а после смерти запускается следующий
биом по кругу. Смена биома меняет материалы и правила ряда, но не накладывает
цветофильтр на экран.

## Структура

```

  Game.ts          — состояния игры, ввод, камера, цикл, интеграция UI/звука
  SceneView.ts     — renderer, сцена, небо, свет, окружение
  World.ts         — генерация мира, физика прыжков, трафик, смерть, очки
  Models.ts        — 3D-модели машин, бревен, поезда, монет и персонажей
  RowModels.ts     — статические ряды, трава, вода, реквизит, тени машин
  Voxel.ts         — общий куб, instanced-меши и blob-тени
  Particles.ts     — частицы (пыль, брызги, монеты, перья)
  UI.ts            — HUD, меню, пауза, game over, магазин скинов
  Portraits.ts     — 2D-портреты скинов для карточек магазина
  AudioEngine.ts   — процедурная музыка, эмбиент под биом и звуки
  save.ts          — сохранение и валидация прогресса
  biomes.ts        — 14 биомов, палитры, сложность и механики
  config.ts        — скины, константы мира и транспорта
  types.ts         — общие типы
  assets/          — арт монеты, предоставленный автором проекта

legacy/            — старая Canvas-версия, сохранена как рабочий fallback
```

## Технические решения

- Ряды мира позиционируются по `z`, машины/брёвна/монеты — локально внутри ряда.
  Ширина рядов — 150 единиц, горизонтальный ход игрока ограничен ±30; это
  гарантирует, что камера всегда видит только застроенную часть карты.
- Земля и рельсы — статические instanced-меши; трава и вода получают
  процедурные текстуры, созданные кодом. Отсечение по пирамиде видимости для
  рядов отключено, а зелёная подложка рисуется без depth-теста, поэтому она не
  может перекрыть дороги и образовать зелёный клин с «висящими» машинами.
- Рендер идёт в полном разрешении экрана с `antialias` и pixel ratio до 2×;
  низкополигональные материалы и кубические формы дают воксельный стиль.
- Машины двигаются внутри ряда и заворачиваются относительно игрока, поэтому
  трафик не заканчивается. У всех машин одной полосы общая скорость, а на
  закольцованном стыке оставлен запас: после заворота соседние машины не
  перекрываются.
- Камера геймплея и меню — `OrthographicCamera` с фиксированным диагональным
  изометрическим углом, центрированная на игроке и следующая за ним с
  демпфированием. Масштаб подбирается под формат экрана.
- Трава, вода, небо и тени генерируются кодом на canvas — внешних ассетов нет.
- Игра рассчитана на WebGL2; при отсутствии контекста показывается понятное
  сообщение.

## Генерация арта (Nano Banana 2.1)

Локальный стек: **PyTorch 2.11 + CUDA 12.8**, **Diffusers**, **Animagine XL 3.1**
и **IP-Adapter Plus SDXL**. Арт Ditoshey для меню сгенерирован длинным
промптом по четырём референсам персонажа (четыре уха, розово-лавандовые
волосы, зелёные глаза, лавандовый костюм-скелет) и встроен в карточку и
меню-панель. Скрипты и модели лежат в `D:\AI\sd`; исходный арт —
`preview-ditoshey-nano-1c48eaf74d.jpg`.

## Legacy

Папка `legacy/` содержит предыдущую Canvas 2D-версию со своим `index.html`,
стилями и smoke-тестом. Она оставлена как запасной рабочий вариант и не
используется новым Three.js-клиентом.

## Дисклеймер

RGG Road — самостоятельный независимый проект. Crossy Road — торговая марка
Hipster Whale; проект не связан с авторами оригинальной игры. Модели, текстуры,
звуки и код созданы для этого проекта; материалы оригинальной игры не используются.

## Переработка моделей

Все персонажи, кроме **Moryaka**, пересобраны вручную. У Moryaka оставлена
прежняя модель: пересборка по референсу itsMORIKO не прижилась, поэтому она
возвращена, а фиолетовый блок-«объём капюшона» за головой убран — сзади он
читался как плита. Коричневые массы волос, белая прядь, очки с фиолетовой
рамой, асимметричные уши и костюм с жёлтыми акцентами на месте.

- **SeverinaSoda** — кигуруми-пижама удильщика: на капюшоне два «гугли-глаза»,
  зигзаг зубов вокруг лица, приманка с золотым колокольчиком, боковые плавники;
  внутри — лицо девочки с розово-лавандовым каре; комбинезон с кремовым животом,
  завязками, зелёными перепончатыми ступнями и рыбьим хвостом.
- **Ditoshey** — длинные волнистые волосы с лавандовым затуханием, четыре уха,
  комбинезон-скелет.
- **HiganBanBan** — детальная голова: слоистое каре, паутинная лилия, ахоге,
  новый костюм с галстуком.
